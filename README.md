# سرکار — دفتر کار عراق 💼

اپلیکیشن وب **کاملاً آفلاین** برای مدیریت کار در عراق — بدون اینترنت، بدون سرور، همهٔ داده‌ها فقط روی گوشی خودت.

## امکانات

- **شمارش روزهای اقامت**: تاریخ ورود به عراق را ثبت کن؛ اپ به‌صورت زنده می‌گوید «X روز تا خروج باقی مانده»، «امروز آخرین روز کاریه — فردا باید بری!» و… (پیش‌فرض: ۳۰ روز اقامت = ۲۹ روز بعد از ورود، قابل تغییر در تنظیمات)
- **تقویم شمسی + میلادی همزمان**: همه‌جا تاریخ هر دو تقویم کنار هم نمایش داده می‌شود
- **ثبت روزانه**: کارکردم / مرخصی (با حقوق یا بی‌حقوق) / کار نکردم + ساعت اضافه‌کاری + یادداشت برای هر روز؛ همهٔ روزها قابل ویرایش و حذف
- **حقوق و اضافه‌کاری**: پیش‌فرض ۲۳٫۳ هزار دینار در روز و ۲٫۳ هزار دینار به‌ازای هر ساعت اضافه‌کاری — جمعه‌ها حقوق ۲ برابر (بدون اضافه‌کاری) — همهٔ نرخ‌ها در تنظیمات قابل تغییر
- **جمع ماهانه بر اساس ماه میلادی** (مثل روش پرداخت کارفرما) با ثبت دریافتی‌ها: کامل، نصف، ۲۰٪ یا مبلغ دلخواه — و نشان‌دادن ماندهٔ هر ماه
- **آمار هفتگی و ماهانه** با نمودار
- **بدهی‌ها**: ثبت بدهی به افراد + پرداخت‌های جزئی + ماندهٔ کل
- **مرخصی‌ها**: شمارش روزهای مرخصی در آمار
- **پشتیبان‌گیری**: خروجی و ورودی فایل JSON
- **نصب روی گوشی (PWA)**: مثل اپ معمولی نصب می‌شود و آفلاین اجرا می‌شود
- تم تیره/روشن، کاملاً فارسی و راست‌به‌چپ

## اجرا

- آنلاین در مرورگر: فایل‌ها را روی هر هاست استاتیک بگذارید (یا همین مخزن را GitHub Pages کنید)
- آفلاین شخصی: پوشه را روی گوشی/کامپیوتر نگه دارید و `index.html` را با مرورگر باز کنید
- نصب به‌عنوان اپ: در کروم اندروید → منو → «Add to Home screen / نصب برنامه»

## ساختار

```
index.html            صفحهٔ اصلی
css/styles.css        استایل (تم تیره/روشن)
js/jalali.js          تبدیل دقیق شمسی ↔ میلادی (آفلاین)
js/core.js            منطق محاسباتی (تست‌پذیر)
js/app.js             رابط کاربری
sw.js                 سرویس‌ورکر اجرای آفلاین
manifest.webmanifest  مانیفست نصب PWA
test/render-test.js   تست‌ها (node test/render-test.js)
```

## تست

```bash
node test/render-test.js
```

> داده‌ها در `localStorage` مرورگر ذخیره می‌شوند. هر چند وقت یک‌بار از تنظیمات «خروجی پشتیبان» بگیرید.
